How it works

A router, not a summary

The reference stays verbatim. A thin navigation layer teaches the agent how to find the exact slice — so any agent, with zero context, lands on the right answer.

1 · Install

Drop the shopify-development folder into your agent's skills directory. Works with Claude Code, Amp and Cursor.

2 · Auto-load

On any Shopify task the agent loads SKILL.md — the router with task-routing and the lookup protocol.

3 · Exact lookup

It greps the symbol index, opens the right reference file at the right heading, and reads only that slice. Verbatim, never guessed.

FAQ

Questions, answered

What exactly is Uppify?

An installable knowledge skill that gives your AI coding agent the complete Shopify developer documentation, indexed so it looks up the exact, verbatim reference for any task instead of guessing.

Which AI agents does it work with?

Claude Code, Amp, Cursor — and any agent that can read a folder of Markdown skills. You drop the shopify-development folder into your agent's skills directory.

How is this different from just reading shopify.dev?

The docs are reorganized as a 1:1 reference plus symbol indexes and task-routing, so an agent with no context navigates straight to the precise heading it needs — fast, scoped, and traceable to the source.

What does it cover?

Themes & architecture, the full Liquid reference, theme APIs, custom apps & extensions, headless & Hydrogen, Shopify Functions, custom data, and AI/agentic commerce — 18 chapters, ~648 pages.

Is it free?

Yes — free to install and use from GitHub.
